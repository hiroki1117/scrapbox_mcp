# Scrapbox WebSocket 仕様メモ

## commit の changes

| 操作 | 形式 | 意味 |
|------|------|------|
| 挿入 | `{"_insert": "<lineId>", "lines": {"id": "<newLineId>", "text": "..."}}` | 新しい行を `<lineId>` の行の**直前**に挿入する |
| 末尾に追加 | `{"_insert": "_end", "lines": {...}}` | ページの末尾に追加する |
| 更新 | `{"_update": "<lineId>", "lines": {"text": "..."}}` | 行のテキストを置き換える |
| 削除 | `{"_delete": "<lineId>", "lines": -1}` | 行を削除する |

### ハマりポイント: `_insert` は「直前」に入る

- `_insert` は「指定した行の後ろ」ではなく「**指定した行の前**」に挿入する
- 「直前に挿入した行の ID」を次の `_insert` に指定して連続で挿入すると、行が**逆順**に並んでしまう
  - 以前の `edit_page` では、元のページより行を増やすと、追加した行が元の最終行の直前に逆順で入るバグになっていた
- 正しい方法
  - 末尾に順番どおり追加するなら、すべて `"_end"` を指定する
  - 途中に挿入するなら、挿入したい位置の「次の既存行」の ID を、連続する挿入すべてに同じように指定する（[@cosense/std の diffToChanges](https://jsr.io/@cosense/std) と同じ方法）
  - 逆順に組み立てて、直前に挿入した行の ID を指定していく方法でもよい（`CreatePage` はこの方法）
